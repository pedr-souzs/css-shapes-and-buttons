# CSS Shapes and Buttons

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css&logoColor=white)

Projeto de prática em **HTML e CSS** que explora dimensões, formas geométricas e componentes de interface estilizados por meio do Box Model.

## Sobre o projeto

A página reúne elementos geométricos coloridos e três botões com tamanhos diferentes, permitindo comparar propriedades de largura, altura, margens, bordas e preenchimento.

## Exercício 1 — Formas geométricas

- Quadrado vermelho.
- Retângulo verde com largura maior que a altura.
- Retângulo roxo com altura maior que a largura.
- Retângulo rosa contendo um quadrado azul-claro.

## Exercício 2 — Botões

Três botões identificados como **Pequeno**, **Médio** e **Grande**.

Todos utilizam as mesmas cores de texto e fundo, o mesmo tipo de borda e o mesmo `border-radius`. As dimensões são modificadas por meio do `padding`, sem definir `width` nos botões. As margens usadas no arquivo CSS também variam e alteram o espaço ao redor dos elementos.

## Tecnologias utilizadas

- HTML5.
- CSS3.

## Conceitos praticados

- Box Model: conteúdo, `padding`, `border` e `margin`.
- Propriedades `width` e `height` nas formas.
- `padding` para dimensionar botões.
- Cores de fundo, bordas e `border-radius`.
- Flexbox para distribuição dos elementos na página.

## Como executar

1. Clone ou baixe o repositório.
2. Abra `index.html` em um navegador.
3. Consulte `style.css` para comparar as dimensões e os espaçamentos.

## Objetivo

Praticar a construção de elementos visuais simples e compreender a influência do dimensionamento e dos espaçamentos no layout.
