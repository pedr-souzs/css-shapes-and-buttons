# CSS Shapes and Buttons

Projeto de prática em HTML e CSS desenvolvido para explorar conceitos fundamentais de estilização e construção de elementos de interface.

## Sobre o projeto

O projeto é dividido em duas partes:

### Formas geométricas

Criação de elementos utilizando HTML e CSS, incluindo:

* Quadrado vermelho
* Retângulo verde com largura maior que altura
* Retângulo roxo com altura maior que largura
* Retângulo contendo um quadrado em seu interior

### Botões

Criação de três botões com diferentes tamanhos:

* Pequeno
* Médio
* Grande

Os botões utilizam a mesma cor de fundo, cor de texto, borda e border-radius. A diferença de tamanho é obtida exclusivamente por meio da propriedade `padding`, sem utilização de `width`.

## Tecnologias utilizadas

* HTML5
* CSS3

## Conceitos praticados

* Box Model
* Width e height
* Padding
* Border
* Border-radius
* Dimensões de elementos
* Estruturação de componentes com HTML e CSS

## Objetivo

Praticar os fundamentos de CSS por meio da construção de elementos simples, compreendendo como propriedades de dimensionamento e espaçamento influenciam o layout de uma página web.
